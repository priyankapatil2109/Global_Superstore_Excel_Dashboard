# 📊 Global Superstore Sales Analysis & Excel Dashboard

## 📌 Project Overview

This project focuses on analyzing the Global Superstore dataset using Microsoft Excel. It transforms raw sales data into meaningful business insights through data cleaning, advanced Excel formulas, PivotTables, charts, and an interactive dashboard.

The dashboard helps users understand sales performance, profitability, regional trends, product categories, and monthly business performance.

## 🎯 Project Objectives

- Clean and prepare raw sales data for analysis.
- Analyze sales and profit across regions, markets, and product categories.
- Practice advanced Excel formulas and lookup functions.
- Summarize business data using PivotTables.
- Create charts and KPI summaries for business reporting.
- Present sales insights through a structured Excel dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Excel Tables and data-cleaning techniques
- VLOOKUP
- INDEX-MATCH
- IF and Nested IF
- PivotTables
- Charts and conditional formatting
- Dashboard design and KPI analysis

## 🔍 Analysis Performed

### 1. Data Cleaning and Preparation
- Organized raw and cleaned datasets.
- Prepared data for analysis and reporting.
- Used Excel Tables to structure the data.

### 2. Advanced Excel Formulas
- **VLOOKUP:** Retrieves information from reference tables.
- **INDEX-MATCH:** Performs flexible lookup operations.
- **IF:** Applies logical conditions.
- **Nested IF:** Categorizes data based on multiple conditions.

### 3. PivotTable Analysis
- Sales and profit by region.
- Sales and profit by category and sub-category.
- Monthly sales and profit trends.
- Market-wise and category-wise sales comparisons.

### 4. Data Visualization
- Created charts to compare business performance.
- Presented KPIs and summary information in a dashboard.
- Used conditional formatting to improve readability.
